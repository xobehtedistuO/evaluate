# Evaluate — xobehtedistuO Performing Arts

Working replacement for the broken Higgsfield route:
`https://xobehtedistuo-talent-agency.higgsfield.app/evaluate`

## Go live (2 minutes)

1. Repo Settings → Pages → Deploy from branch → `main` / root.
2. Public URL becomes: https://xobehtedistuo.github.io/evaluate/
3. Submit the form once yourself. FormSubmit will email `xobehtedistuotalent@gmail.com` a confirmation link. Click it. After that, every client submission lands in Gmail as a table.
4. Optional: point `evaluate.xobehtedistuo.com` at GitHub Pages and add a `CNAME` file with that host.

Do not send clients back to the Higgsfield `/evaluate` URL until that host stops returning “This page didn’t load.”
